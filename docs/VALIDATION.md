# 公开验证摘要

日期：2026-10-31。公开摘要保留兼容条件、结果与哈希，不公开设备标识、运行时地址和原始私人日志。

- 在 [支持组合](COMPATIBILITY.md) 验证 Shizuku 无线调试 UserService：UID 2000、u:r:shell:s0、Seccomp 0。
- 恢复后 KernelSU 模块 Live，App 实际返回 uid=0(root)、u:r:ksu:s0，SELinux Enforcing。
- 完整重启后，由手机 App 经 Shizuku 独立恢复；机主随后再次重启并复验成功。
- 2.0 的旧管理器进程可能显示未安装；2.0.1 补回加载前停止／完成后重新启动，实测显示工作中、越狱模式、LKM。
- 2.1.0 为界面包装更新，17 项核心输入、18 个核心编译类与执行声明一致。公开摘要见 [2.1.0 核心快照](../release/v2.1.0-core-files.json)。
- 准备条件、执行身份、同次／跨次开机、路径、成功条件、UTF-8、退出码、超时、输出上限测试通过。

不是大样本成功率或所有固件保证。实际 APK 哈希和签名证书指纹见 [发布清单](../release/v2.1.0.json)。构建成功与实机利用成功是不同证据。

## 2.2.0（2026-11-01）

新增用户可选调试工具 Root，默认关闭。已验证原模板两分支只在 allow_shell 条件值上不同，boot_id 修复、用户空间初始化与 SELinux 收尾保持一致。8 个原载荷与其余原核心文件不变；RecoveryEngine 增加设置读取与参数传递，原始哈希与当前哈希分别保留。已有运行不重新加载的分支保留。

本地单元测试、完整 APK 构建与原签名校验通过。新增开启模式尚未进行支持设备上的实机复验；前述旧版实机成功不等同于新增选项已实机验证。当前发行元数据见 [v2.2.0.json](../release/v2.2.0.json)。

## 2.3.0（历史候选阶段）

界面与可访问性更新。执行核心、AIDL 与 8 个载荷文件与 2.2.0 逐字节一致；新增的三个纯 Java 类有 3 组单元测试（状态机、错误归类、导出头）。本地以 SDK 35 完整构建未签名 APK 通过，发布与证据校验脚本通过。尚未在 ANB-AN00 上运行，因此不发布签名 APK，也不更新 `release/SHA256SUMS.txt`。审计与验证矩阵见 [AUDIT_2.3.0](AUDIT_2.3.0.md)，版本入口见 [current.json](../release/current.json)。

## 2.3.3（2026-11-02）

App 控制层、错误处理、任务与界面生命周期已更新。8 组 JVM／替身测试、公开源码与隐私检查、历史证据检查、完整构建及包完整性检查按 [审计闭环](AUDIT_2.3.3.md) 验证。当前版本以 [current.json](../release/current.json) 为准。

本轮没有连接设备，没有实际运行手机提权或重启恢复。元数据的 `device_verified=false`、`requires_device_reverification=true` 如实保留；旧版或其他会话的结果不自动转移到新控制代码。只有载荷与 AIDL 保持原字节，旧版“整个核心不变”的描述不适用于 2.3.3。
