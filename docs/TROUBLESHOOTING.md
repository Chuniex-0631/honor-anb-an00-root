# 故障排查

| 现象 | 处理 |
|---|---|
| Shizuku 未运行 | 通过无线调试启动，返回检查 |
| 权限被拒绝 | 在 Shizuku 的应用管理中允许 ANB Root |
| 当前为 Root 启动 | 停止 Shizuku，改用无线调试启动，以验证无 Root 新开机的环境 |
| 开机时间不足 | 解锁并等待开机约 90 秒 |
| App 已验证，KernelSU 显示未安装 | 记录页刷新 KernelSU，结束旧管理器进程 |
| 模块存在，App 等待授权 | KernelSU → 超级用户中允许 ANB Root，再返回验证 |
| 断开／超时 | 不自动重跑，先保存诊断，按提示重新启动后再试 |
| 型号／完整固件／内核不匹配 | 停止恢复；不要换入其他机型或版本的载荷 |
| SELinux 未恢复为 Enforcing | 保存诊断并完整重启；不要继续使用本次未完成的 Root |
| 本次开机已有尝试但记录不可用 | 保存诊断并完整重启；不要删除锁或连续重跑 |
| 无法打开诊断保存页面／导出失败 | 解锁手机，确认所选保存位置可写，再重新导出；记录也可先在页面查看或复制 |

Issue 仅提供型号、固件、内核、App/Shizuku/KernelSU 版本、步骤与脱敏相关片段。不要提交完整 Bugreport、私钥、设备标识、账号或签名密钥。

本地会保留执行环境与验证摘要。导出文件由你选择保存位置；App 不会自动上传。卸载 App 不会立即卸载本次开机已加载的内核模块；需要完整重启才能结束临时 Root。
