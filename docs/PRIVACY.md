# 公开材料与脱敏边界

保留公开型号、固件、内核、必要配置、结果、上游归属、公开源码提交及校验值。原 config.gz 保持原字节和哈希，避免借脱敏篡改证据。

不发布：

- ADB 私钥、签名 keystore、密码或令牌。
- 设备序列号、IMEI、SIM／账号标识、网络地址或完整设备日志。
- 私人邮件正文、内部消息 ID 或私人会话标识。
- 操作者个人目录、私有缓存或未经审查的备份。
- 本地实验的精确运行时内核地址、进程号与完整现场记录。

执行环境与验证摘要自动保存在本机 App 专属外部文件目录；恢复选项与本次运行标记保存在 App 私有配置中。恢复链还在 `/data/local/tmp/anb_root_runs` 留存运行记录及目录锁，不能把删除记录当作安全重试方法。手动导出时由用户选择保存位置；导出副本不会随卸载自动删除。App 不申请联网权限，不自动上传记录。

界面图只展示程序非私人内容，完整本地诊断不上传。CI 标准 /home/runner/work 路径是公开构建环境信息，不当作个人目录。
