# 公开材料与脱敏边界

保留公开型号、固件、内核、必要配置、结果、上游归属、公开源码提交及校验值。原 config.gz 保持原字节和哈希，避免借脱敏篡改证据。

不发布：

- ADB 私钥、签名 keystore、密码或令牌。
- 设备序列号、IMEI、SIM／账号标识、网络地址或完整设备日志。
- 私人邮件正文、内部消息 ID 或私人会话标识。
- 操作者个人目录、私有缓存或未经审查的备份。
- 本地实验的精确运行时内核地址、进程号与完整现场记录。

界面图只展示程序非私人内容，完整本地诊断不上传。CI 标准 /home/runner/work 路径是公开构建环境信息，不当作个人目录。

本次检查历史独立文件版本和提交者身份，清理私人邮件编号与非公开提交邮箱，保留时间线和结论。历史改写改变提交 SHA，旧 clone 应重新克隆或明确重置。

仓库当前公开。旧 Private 描述仅属于当时状态。改写不能保证第三方副本或 GitHub 缓存消失；本页不作这种保证。

脱敏遗漏按 [安全政策](../SECURITY.md) 报告，不在公开 Issue 中粘贴敏感内容。

## App 运行时存储

- App 内部私有目录保存 `recovery-v2.log`；仅在用户选择“保存诊断记录”时通过系统文件选择器导出该日志。
- 每次环境探测和验证可能在 Android App 专属外部目录写入 `environment-shizuku.txt`、`verification.txt`，准备阶段在其 `payload-v2/` 存放暂存载荷与渲染脚本。这些文件并非用户手动导出的诊断记录。
- 专属外部存储不代表对持有 ADB/shell/Root 权限的调试工具保密；共享、备份或交付设备前应检查并清理相关文件。App 不通过网络上传这些内容。
