# 资料规范与长期同步机制

> 历史研究快照（截至 2026-10-11）。本页保留当时结论；当前结果见 [研究历史与发布状态](RESEARCH_HISTORY.md)。

## 证据等级

- **A 实机：** ANB-AN00 的原始命令回显、经过哈希检验的文件或能复现的设备行为。
- **B 官方：** HONOR 开源、官方产品说明和可验证的厂商资料。
- **C 第三方：** GitHub 代码、固件索引、社区维修帖子；仅能证明有人发表线索，未必适用当前设备。
- **D 推测：** 尚无实机证据的可能性，必须标明待验证。

P780 的实验结论只能作为方法论，不自动作为 ANB 的 A 级证据。

## 每次里程碑必须同步

1. 更新 STATUS：哪些命题改变，哪些仍被阻断。
2. 更新相关专题：可追踪来源、型号/版本、实验原始回显及失败原因。
3. 更新 EVIDENCE_MANIFEST：文件名、来源、字节大小与**实际计算过**的 SHA-256。
4. 更新 HISTORY、CHANGELOG 与 README；必要时**修改旧结论或重组文件**，不要单纯追加。
5. 新增 CI 测试时保留运行编号、源码 commit、编译器、Kconfig diff、错误日志；编译成功不等于原厂固件二进制或漏洞成功。

## Private 仓库和历史公开风险

目前仓库为 Private，但首次初始化时曾是 Public。始终不提交 IMEI、SN、SIM、MAC、通讯记录、私有 OTA token 或未经检查的完整 bugreport。删除文件或修改可见性无法保证抹除过去的公开历史，必须先脱敏。

## 实机安全

先只读取证。没有完整匹配固件与可信恢复方案时，不使用其它机型 EDL loader、刷写 boot/abl/vbmeta、强制降级或高崩溃风险的内核 PoC。
