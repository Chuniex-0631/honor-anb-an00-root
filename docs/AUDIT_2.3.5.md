# 2.3.5 列表按压反馈修复

日期：2026-11-02。基线：2.3.4 正式版。用户要求参考手机设置列表的交互样式，保留原配色，将列表项按压反馈改为左右贯通的矩形。参考截图仅留在本机，不公开其中的账号、网络或其他私人内容。

## 调整内容

- 首页四个准备项、帮助页六个常见问题，以及恢复选项行，使用一致的列表按压反馈。
- 卡片左右内边距移至行内，文字、状态点和开关的位置保留；高亮覆盖整行卡片宽度。
- 使用状态背景提供均匀的矩形高亮，松手后短暂淡出；不再显示内缩圆角矩形或局部波纹。
- 浅色、深色继续使用各自原有的 `ripple` 颜色；卡片外轮廓仍为圆角，内容裁切在卡片范围内。
- 普通操作按钮、版本入口与底部导航保留各自的外观，不改成列表行。

## 验证

真实生产 Activity 的 UI-only instrumentation 增加整行边界、矩形圆角半径、原颜色和反馈类型检查。覆盖四个准备项、六个 FAQ 和选项行，不调用真实恢复入口。

恢复引擎、Shizuku 连接、任务控制、命令运行、8 个载荷、AIDL 和配色资源均与 2.3.4 保持原字节。本版只有 Activity 展示代码、版本与第三方声明文本变化；没有重新执行提权或重启测试。
