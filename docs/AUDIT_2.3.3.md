# 2.3.3 审计修复与复核

日期：2026-11-02。基线：2.3.2 发布代码及 `bd33e6f` 文档快照。本版修复 App 的执行控制和界面状态；8 个原始载荷及 AIDL 不变。

## 问题闭环

| 原发现 | 2.3.3 修复 | 复核方式 |
|---|---|---|
| A01 固件放行缺口 | DeviceProfile 同时精确检查机型、Android SDK、完整固件标识、内核；执行前通过 Shizuku 再读属性 | 纯逻辑负向测试；实际引擎 + 模拟 shell 拒绝错误固件 |
| A02 失败死路／旧结果覆盖前置条件 | 当前 gate 优先；开机等待可重新恢复，超时只检查旧进度；验证操作禁止启动新恢复链 | 组合状态测试；实际引擎验证-only 与重复恢复用例 |
| A03 保护状态误报存储 | RecoveryFailure 提供结构化错误类型；SELinux 错误单独提示保存记录并完整重启；不再以“保存”泛化存储错误 | 旧原文回归、实际引擎 Permissive 用例 |
| A04 重复启动撤掉前台状态 | Service 明确持有任务；重复请求不撤前台、不停止原任务；销毁后忽略旧回调 | 实际 RecoveryService + 最小框架替身 |
| A05 检查／恢复并发 | 所有任务共用 TaskGate 所有权，设置写入也受保护，旧任务不能释放新租约 | 并发测试；实际引擎阻塞探测时拒绝恢复与设置 |
| A06 子进程与输出清理 | finally 清理自有控制进程及流；关闭 stdin；传播中断，拒绝不完整输出；不杀自主载荷进程组 | 真正的 JVM 子进程中断清理、EOF／输出／超时测试 |
| A07 Activity 迟到回调 | 暂停／销毁清空私有 Handler；仅 resumed 页面可注册刷新；导出完成通过弱引用返回界面 | 生命周期控制流复核、全量 Android 编译；手机生命周期回归仍需实测 |
| A08 主线程导出 | 文档提供者的打开、写入、关闭均在独立 I/O 线程，目标明确后才执行 | 线程控制流复核、全量编译；慢 provider 场景仍需实测 |
| B01 状态协议／目录绑定 | 只解析严格头部，日志尾部不参与判定；cd 失败即返回；目录 boot 必须匹配；丢失记录但锁存在时拒绝重跑 | 伪造尾标记、错误 boot、实际引擎丢失记录用例 |
| B02 选项行与无障碍 | 父行和 Switch 同步禁用；父行暴露 Switch 角色与选中状态；说明显示保存的选择 | Android API／控制流复核；TalkBack 仍需手机确认 |
| B03 诊断与版本说明 | 导出本机实际内核和已读取 boot；当前文档按版本记录，纠正旧审计的误报 | 导出格式测试、文档／元数据检查 |
| B04 链路副作用／连接关闭／产物 | 披露上游 region 标识与 ksud 阶段；连接关闭与迟到回调加保护；UserService 版本升为 10，以更新旧缓存代码；发布包核对当前构建的 DEX、Manifest 和资源 | 代码复核、签名及资产／产物比对 |

补充修复：验证已有模块时保留原运行目录；通知权限回调不再绕过当前生命周期和任务检查；等待结束仍是 Permissive 时用保护状态错误提示。开机状态、载荷校验、目录锁、恢复时序和 KernelSU 管理器刷新仍保留。

## 验证与边界

- 8 组测试：既有 workflow、options、status、failure text、diagnostics，以及审计回归、真实引擎 + 模拟 shell、真实 Service + 框架替身。
- 引擎测试中所有 shell 命令均被记录和模拟，真实 `/system/bin/su` 与载荷不会在测试机执行；进程清理用例只运行自己创建的普通 Java 子进程。
- 当前公开源码、隐私、历史证据、链接、依赖哈希、完整构建及正式包签名和载荷校验分别检查。
- 本版自有执行控制代码已变化，不能继承旧版“整个核心逐字节不变”或“新版本已实机 Root 验证”的结论。发布元数据如实记录 `device_verified=false`、`requires_device_reverification=true`。
- 本次复核范围内未保留上一轮发现的代码缺陷；这不等于没有任何潜在问题。未进行完整 native 二进制逆向，设备上提权、重启恢复、慢文档提供者和 TalkBack 仍需实机回归。
