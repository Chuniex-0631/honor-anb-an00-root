# ANB Root · v2.2.2 单页 UI 与操作逻辑审查（候选版）

**状态：未正式发布。** 代码基于审计 PR #1 和 UI PR #2，运行时 Root 载荷与 KernelSU LKM 原样保留。正式稳定版仍为 v2.2.0；测试版 2.2.1 UI RC1 是预发布独立包，不代表正式 v2.2.1 已发布。

## 信息布局

单个垂直 ScrollView，依次展示 Root 状态、设备与环境、恢复进度（条件显示）、调试授权选项、横排「打开 Shizuku」「打开 KernelSU」、诊断记录／导出／帮助。固定底部仅有一个主操作按钮，不存在标签页。卡片内边距 15–16dp、卡片间距 11dp，正文保持 13–15sp，点击热区 ≥48dp。移除页眉绿色 A，保留纯文本标题。

## 状态与操作对照

| 条件 | 主操作 | Shizuku 快捷按钮 | KernelSU 快捷按钮 |
|---|---|---|---|
| 设备/固件不适配 | 不可用 | 打开 Shizuku/下载 | 打开 KernelSU/下载，不刷新 |
| Shizuku 未安装、未启动或未授权 | 下载/启动/授权 Shizuku | 直接打开/下载 | 直接打开/下载，不刷新 |
| KernelSU 未安装 | 下载官方 v3.3.0 | 直接打开 | 下载页 |
| 环境尚未检查 | 检查环境 | 打开 | 直接打开，不刷新 |
| 首次环境就绪 | 确认首次准备 | 打开 | 直接打开，若已有模块且 READY 才可刷新 |
| 可恢复 | 恢复 Root | 打开 | 模块未加载时只打开 |
| 恢复中/环境检查中 | 主按钮禁用 | 可以打开 | 只打开，绝不 force-stop |
| 等待授权 | 验证授权 | 打开 | 模块已加载并 READY 时使用旧刷新，否则直接打开 |
| Root 成功 | 重新验证 | 打开 | 模块已加载并 READY 时执行旧刷新 |
| 本次失败 | 仅重新检查环境 | 打开 | 不触发提权；按安全门禁打开/刷新 |

KernelSU 智能按钮的刷新必须同时满足：软件已安装、`!busy`、`!checking`、`modulePresent` 且 `gate()==READY`；调用**已有** `RecoveryEngine.refreshManagerOnly()`，不可再额外调用 `openPackage()` 造成二次启动。否则调用普通打开，不改变后台提权任务。此按钮任何路径都不得调用 `startRecovery()`。

## 交互保护

- `UiState` 决定唯一主按钮的文案和能否执行，恢复前仍由 `RecoveryEngine` 重新检查兼容性、固件指纹、Shizuku 权限与同次开机任务状态。
- 调试工具 Root 授权默认关闭，开启需要清楚的高权限风险确认。检查中、恢复中、模块已加载时禁止切换；撤销已经加载的 shell 授权需要完整重启。
- 恢复失败不自动重试；诊断与日志导出始终可找到。大日志只渲染最后 32,000 字符，完整内容仍导出。
- 暗色模式、屏幕旋转及恢复过程中的状态刷新不能重置 Root 任务或意外改变开关；单页保留滚动位置与日志展开状态。
- 无新权限；保留 Shizuku、通知权限与文件选择器导出逻辑。

## 新图标

盾牌外形＋小钥匙，深绿 `#154734` 背景、白色 `#F1FFF5` 盾牌及浅绿 `#9DE4B9` 钥匙。108dp viewport，所有笔画位于居中直径 66dp 圆形安全区内，支持 Adaptive/Legacy/Android 13+ Monochrome。旧三个导航图标已不再使用。
